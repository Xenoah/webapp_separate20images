# 隙間トリム写真分割

写真を複数枚に分割するブラウザツール。分割数と、並べたときの隙間に隠れる部分のトリム量を設定できます（両端はトリムしません）。画像は端末内で処理され、どこにも送信されません。

https://xenoah.github.io/webapp_separate20images/

## 初期設定

20枚・横方向・隙間px指定・トリムON・JPEG・スマホ横スクロール表示で開始します。初期画像は○テスト画像です。

隙間の初期値は、1枚の幅の8%相当を元画像の整数pxに換算します（○テスト画像は48 px）。画像サイズや分割数を変えると初期値を再計算します。隙間を手入力した後は、そのpx値を保持します。「Xモバイル初期設定に戻す」で20枚・px指定と初期値の自動換算を復元できます。極小画像では分割数や隙間を画像サイズに合わせて制限します。

pxは元画像の寸法です。Xの画面上のpx数をそのまま入力する指定ではありません。

## Xモバイル向けの○テスト

「○テスト画像」を押すと、寸法を固定した真円・直線・外端マーカーの画像を読み込みます。

- 元画像: 12912 × 800 px
- 20枚、横方向、隙間48 px（8%相当）、トリムON、PNG
- 1枚: 600 × 800 px（3:4）、隙間: 元画像48 px、両端は保持
- 青い○は各画像内の縦横比、橙の○は画像間の継ぎ目を確認するためのものです。
- 「スマホ横スクロールで確認」で隙間を含む表示を確認できます。
- ZIPを展開し、01〜20の順でXへ添付してください。対応端末では「画像をまとめて共有」も利用できます。共有先の受け取り枚数は端末やアプリに依存します。

8%は校正用の初期値であり、Xの公式固定仕様ではありません。Xアプリ・端末・表示モードにより隙間やクロップが変わるため、実際の投稿表示で調整してください。ブラウザ内のプレビューはXアプリそのものの再現ではありません。

## 安定性

- 分割数は画像の長さまで（最大50枚）に制限。1 px画像も扱えます。
- トリムOFFでは奇数寸法でも1 pxの抜け・重複がありません。
- 設定変更・画像読込の開始時に旧出力の保存を停止し、最後の設定で生成します。
- PNGは透明を保持、JPEGは白背景に合成します。
- ZIPはUTF-8ファイル名・連番・CRC32付きです。
- 連続ダウンロードの完了は端末側で確認してください。保存要求だけでは実際の保存完了を判定できません。

## 再テスト

Node.jsで寸法の境界条件を検査:

```sh
npm test
```

`python3 -m http.server 8765` で配信して `http://localhost:8765/tests/browser.html` を開き、「テストを実行」を押すと、実ブラウザで画素比較、画面幅320〜1280 px、20枚出力、透明画像、保存の競合、ZIP内容などを検査できます。公開版は [自動テスト](https://xenoah.github.io/webapp_separate20images/tests/browser.html) で実行できます。

この検査はWebツールの動作を対象とし、Xのネイティブアプリでの投稿結果を保証するものではありません。
